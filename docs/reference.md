# 接口

Web profile 通过 `cordis.patch.yml` 注册单个宿主组件 `llm-antigravity-acp`。DSH 的会话历史是主记录，适配器负责把对话转换为 ACP 请求。可复用时仅发送新内容，历史分支或工具配置变化时重建会话。本机 MCP 桥仅提供本轮 DSH 发布的工具，结果经调用标识返回。ACP 文件和终端能力默认拒绝。

设置 RPC 为 `agyAcp/account` 和 `agyAcp/models`。账户状态读取是被动操作，连接和取消需由用户发起。账户 RPC 的 `verify` 操作验证已有授权，收到需要认证的响应时直接报告；`login` 允许官方进程启动交互授权。模型列表普通读取使用既有目录，显式刷新时向官方服务请求目录。对话实际使用量可以来自 ACP 的会话事件；插件不提供 Google 套餐额度查询。

插件使用 DSH 运行账号的操作系统权限。ACP 权限协商不能替代主机或容器的隔离。插件本身不管理 Google 令牌。处理授权请求和凭据存储属于 Google 官方子进程。
