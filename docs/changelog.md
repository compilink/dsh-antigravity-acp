# 版本记录

## 0.1.49

Web profile 支持从固定的 GitHub 版本地址安装预构建插件。归档附带 macOS 双击登录器，登录器从目标 profile 的已安装依赖加载官方 ACP 登录程序。

## 0.1.49-local.1

个人 fork 的首个 ACP 专用版本。删除订阅代理、CLI 登录态导入、OAuth 换发、后台额度任务及相关设置。账号授权交由 Google 官方程序，插件不在不同登录态之间回退。Google 发行归档在每次启动前按平台核对固定摘要，独立解压主程序与辅助文件。提供商 ID 沿用 `antigravity-acp`，插件包使用独立名称。
